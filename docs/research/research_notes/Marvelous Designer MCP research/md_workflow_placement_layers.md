# How MD users place, drape, layer and sew pattern pieces (GUI workflow), for md-mcp

Researched 2026-10-11 for Marvelous Designer 2026.0.315 (Enterprise Offline). Sources: the official MD and CLO help centres, plus MD/CLO community threads. The help-centre pages block plain fetching (HTTP 403), so they were read through the public Zendesk JSON API (`/api/v2/help_center/en-us/articles/<id>.json`, `/api/v2/community/posts/<id>.json`). Each citation links to the human-readable URL. Items tagged **[Local]** are read-only observations on this machine: the installed 2026.0.315 binary's embedded UI strings, and its app-data folders. They are not web sources. Their purpose is to confirm which GUI names exist in this exact build. MD was not driven, and no repo file other than this one was touched. CLO shares most of MD's tools, and CLO pages are used where MD's own page is thinner. Anything that may be CLO-only is flagged.

## 1. Arrangement: arrangement points, bounding volumes, custom avatars, and the arrangement tools

### Takeaway
MD's own placement model works like this. Each avatar carries **bounding volumes** (BVs): cylinders or cuboids spanned between two joints. **Arrangement points** sit on those BVs. Clicking a point puts the centre of the selected pattern on it and wraps the pattern round the BV's curve. Everything after that is fine-tuning: Property Editor ▶ Arrangement (Position X/Y, Offset, Orientation, Shape Style), the gizmo, arrow keys or Direct Positioning. Pieces sewn to something already draped are placed relative to it, with Superimpose or Smart Arrangement, not with points. On an unusual avatar the fix is to edit the avatar's BVs and points in **Avatar Editor ▶ Arrangement**: resize or add BVs, add or move points, save the `.pan`/`.arr` files and the `.avt`. Nobody works round bad points by drafting short pieces.

### Cited Findings
**Arrangement points (how they are used)**
- Arrangement points are created on the bounding volume surrounding the avatar, and patterns are arranged on the avatar following the BV's curves. "Precise arrangement is available by using Gizmo or Property Editor even after arranging with Arrangement Points." — [Arrange Pattern with Arrangement Points/Flip Wrap Direction](https://support.marvelousdesigner.com/hc/en-us/articles/47358262924185-Arrange-Pattern-with-Arrangement-Points-Flip-Wrap-Direction)
- Workflow: Avatar Display ▶ **Show Arrangement Points**, select a pattern, hover over a point to preview the placement (ver 2.4.0), then click. "The center of the Pattern is now being placed according to the selected Arrangement Point." Symmetric arrangement happens when both patterns and points carry symmetry (ver 3.0.0). — [same](https://support.marvelousdesigner.com/hc/en-us/articles/47358262924185-Arrange-Pattern-with-Arrangement-Points-Flip-Wrap-Direction)
- **Flip Wrap Direction**: patterns longer than the BV (cuffs, for example) wrap in a spiral. Right-click the pattern in 3D ▶ Flip Wrap Direction. — [same](https://support.marvelousdesigner.com/hc/en-us/articles/47358262924185-Arrange-Pattern-with-Arrangement-Points-Flip-Wrap-Direction)
- Hotkeys and toggles in the 3D window's Avatar Display menu: **Show Arrangement Points (Shift+F)**, **Show Bounding Volumes** (separate toggle), **Show X-Ray Joints / Show Avatar Joints (Shift+X)**, Show Avatar (Shift+A). — [3D Window Display Icons](https://support.marvelousdesigner.com/hc/en-us/articles/47358200025497-3D-Window-Display-Icons)
- **Arrangement Property Setting** (3D Toolbar ▶ Select/Move ▶ select a 3D pattern ▶ Property Editor ▶ Arrangement). It is only available for patterns arranged by arrangement points. Fields: **Point Name**, **Shape Style** (flat or curved), **Position X** and **Position Y** ("moves horizontally/vertically according to the arrangement bounding volume"), **Offset** ("adjusts the offset and curvature between the arrangement bounding volume and the pattern"), **Orientation**. — [Arrangement Property Setting](https://support.marvelousdesigner.com/hc/en-us/articles/47358278939417-Arrangement-Property-Setting); identical in CLO: [CLO Arrangement Property Setting](https://support.clo3d.com/hc/en-us/articles/115002101968-Arrangement-Property-Setting)
- **[Local]** The 2026.0.315 binary contains the serialised arrangement keys `ArrangementName`, `ArrangementOffsetX`, `ArrangementOffsetY`, `ArrangementOffsetZ`, `ArrangementOrientation`, `ArrangementType`, `ArrangementPointDataMap`, `ArrangementPointRadius`, and the Python entry points `SetArrangement`, `SetArrangementPosition`, `SetArrangementOrientation`, `SetArrangementShapeStyle`, `ResetClothArrangement`, `ReDrape3DArrangement`. — strings in `C:\Program Files\Marvelous Designer Enterprise Network Offline\MarvelousDesigner_Enterprise_Offline.exe`

**Bounding volumes and arrangement points (editing them)**
- All of this lives in **Main Menu ▶ Avatar ▶ Avatar Editor ▶ Arrangement** tab ("Edit, add or delete any of the Bounding Volumes or Arrangement Points"). The `.AVT` "contains all the information related to Avatars, including ... bounding volumes, and arrangement points." — [Avatar Editor (ver. 2025.0)](https://support.marvelousdesigner.com/hc/en-us/articles/47358128221337-Avatar-Editor-ver-2025-0)
- BV fields in the 2025.0+ editor: Name, **Add** (new BV called "PAN"), **Delete**, **Reset Bounding Volumes**, **Open/Save** (`*.PAN`, "to use with other avatars"), **Joint Name 0** (start joint), **Joint Name 1** (end joint), **Height**, **Radius X (mm)**, **Radius Y (mm)**, **Hands/Feet** (extends the BV to the hands or feet). — [Avatar Editor (ver. 2025.0)](https://support.marvelousdesigner.com/hc/en-us/articles/47358128221337-Avatar-Editor-ver-2025-0)
- The older Add BV page calls the radii "Length X/Y" and adds **Shape** (Cylinder or Cuboid, MD10) and **Round Corner** (cuboid only). "If the order below/above the joint points is reversed, the left and right sides are flipped when arranging the Pattern." — [Add Bounding Volume](https://support.marvelousdesigner.com/hc/en-us/articles/47358365447705-Add-Bounding-Voulme)
- Point fields: **Add** (a point called "Arrangement Point", unassigned by default, "you will need to select the BV and X Y positions"), **Delete**, **Open** (`*.ARR`; "this can be used to apply Arrangement points to an *.OBJ avatar"), **Save** (`*.ARR`, "Some readjustment may be needed when applying to another avatar"), **Arrangement BV**, **X**, **Y**, **Offset** ("Sets the distance between the Avatar and the Arrangement Point"), **Wrap Direction** (up or down). — [Avatar Editor (ver. 2025.0)](https://support.marvelousdesigner.com/hc/en-us/articles/47358128221337-Avatar-Editor-ver-2025-0)
- "Without corresponding Bounding Volume, the Arrangement Point is invisible." Symmetric points use `_L`/`_R` name suffixes. To apply, save the avatar (File ▶ Save as ▶ Avatar) and the points (Arrangement Point ▶ Save), then reload. A light-blue outline marks a symmetric point. Points off the avatar's body are symmetric by default (ver 3.0). — [Add Arrangement Point](https://support.marvelousdesigner.com/hc/en-us/articles/47358324263705-Add-Arrangement-Point)
- Deleting a BV deletes all its points: "assign them to another Bounding Volume to avoid any loss." A selected BV can also be deleted with the Delete key in 3D. — [Delete Bounding Volume](https://support.marvelousdesigner.com/hc/en-us/articles/47358354350873-Delete-Bounding-Voulme)
- **Fit to Avatar (All)** (Avatar Editor ▶ Arrangement ▶ Bounding Volume) re-fits the BVs "according to current avatar size when changing its pose or loading another avatar joints". — [Rearrange Bounding Volume: Fit to Avatar](https://support.marvelousdesigner.com/hc/en-us/articles/47358360672025-Rearrange-Bounding-Volume-Fit-to-Avatar)
- **Reset Bounding Volumes** returns BVs to their original placement. — [Reset Bounding Volumes](https://support.marvelousdesigner.com/hc/en-us/articles/47358375835417-Reset-Bounding-Volumes-ver4-2-0)

**Custom and non-human avatars**
- On OBJ import, *Load as Avatar* has the option **"Add Arrangement Points & BVs"** (ver 4.2.0), which generates BVs and points "fit to the imported OBJ". It "works properly only when imported OBJ is either in T or A pose". Otherwise MD shows "Arrangement Points were not fitted to the avatar. The avatar must be in a T-pose or A-pose." — [3D File (OBJ) Import/Export](https://support.marvelousdesigner.com/hc/en-us/articles/47358223288601); CLO's equivalent is "Automatically Add Arrangement Points", on by default: [CLO Automated Arrangement Point Creation](https://support.clo3d.com/hc/en-us/articles/360001749467-Automated-Arrangement-Point-Creation)
- **Conflict.** MD support wrote in 2023: "It is not possible to do an automatic conversion of the arrangement points on import". Their advice was to scale the custom avatar to MD avatar size "to fit existing arrangement points which you can modify ... on Avatar - Avatar Editor - Arrangement". The fitting suit "will not allow to create a distribution of the different parts of the body ... as not all custom avatars share the same distribution". — [MD community: Arrangement Points – Automatic Generation](https://support.marvelousdesigner.com/hc/en-us/community/posts/48269284495641-Arragement-Points-Automatic-Generation-Feature-Request). The help article above says the import option exists. Read together, the import option is a T/A-pose heuristic fit, not a body-part-aware conversion (inference).
- "Currently we don't have the function to mirror Bounding Volumes. However, if your avatar has joint information and the skeleton is symmetrical, you can ... manually add new bounding Volumes, apply the same setting and attach them to the symmetrical joints." (MD Support, 2022) — [MD community: Symmetrical Bounding Volumes](https://support.marvelousdesigner.com/hc/en-us/community/posts/48273024756249-Symmetrical-Bounding-Volumes)
- A community moderator: "The arrangement points automation is set up for avatars (bi-peds) with limbs and arms. If you are deviating from the norm then it's incumbent on you to ... manually add an arrangement point to a bounding volume using the avatar editor." (2021) — [MD community: Reset 3D Arrangement problem](https://support.marvelousdesigner.com/hc/en-us/community/posts/48283176857753-Reset-3D-Arrangement-problem)
- A version regression: custom avatars' points and BVs broke in 2024.0.149 and were fixed in 2024.0.173. — [MD community post](https://support.marvelousdesigner.com/hc/en-us/community/posts/48267561419673-Arrangement-Points-and-Bounding-Volumes-problems-with-Custom-Avatars-in-the-2024-0-149-version-of-MD)
- **Auto Sewing** "will only work with the Default Bounding Volumes provided by Marvelous Designer, custom Bounding volumes & arrangement points will not work". It expects collars and bands on neck points, bodies on body points and sleeves on arm points. — [Auto Sewing (Ver. 2025.0)](https://support.marvelousdesigner.com/hc/en-us/articles/47358149073305-Auto-Sewing-Ver-2025-0)
- **Auto Convert to Avatar** (Main Menu ▶ Avatar, 2024.0+) converts external avatars into MD avatar types. It is "recommended to be used with a Human-shaped Avatar Mesh in an A-pose". Modes include *Rigging Only* (keeps shape, adds joints) and *Custom (Maintain current rig)*. — [Auto Convert to Avatar](https://support.marvelousdesigner.com/hc/en-us/articles/47358210639897-Auto-Convert-to-Avatar-Ver-2024-0-and-above)
- The IK Joint tab has **Set T-Pose** and notes that "IK mapping may not apply correctly for creatures or quadruped avatars with non-human structures". — [Avatar Editor (ver. 2025.0)](https://support.marvelousdesigner.com/hc/en-us/articles/47358128221337-Avatar-Editor-ver-2025-0)

**The other arrangement commands**
- **Reset 2D Arrangement** "spread[s] and arrange[s] the entire or the selected patterns in the 3D window identical to 2D window state". Selected: 3D right-click ▶ Reset 2D Arrangement (Selected). All: Main Menu ▶ 3D Garment ▶ Reset 2D Arrangement (All), or the 3D toolbar. — [Reset 2D Arrangement](https://support.marvelousdesigner.com/hc/en-us/articles/47358384849177-Reset-2D-Arrangement)
- **Reset 3D Arrangement** returns patterns "back to pre-simulation state". "Use this function when draping is not functioning properly after arranging around the Avatar." Selected and All variants, as above. — [Reset 3D Arrangement](https://support.marvelousdesigner.com/hc/en-us/articles/47358385785881-Reset-3D-Arrangement)
- Users report that patterns arranged by hand fly to random places on Reset 3D Arrangement. Staff acknowledged "an issue with Reset 3D Arrangement" (2021). A moderator explains it returns to the first arrangement-point state, and that otherwise you should save a History state. — [MD community: Reset 3D Arrangement problem](https://support.marvelousdesigner.com/hc/en-us/community/posts/48283176857753-Reset-3D-Arrangement-problem)
- **Fold Arrangement** (Main Menu ▶ 3D Garment ▶ Fold Arrangement, or 3D toolbar): "Fold Seam Allowances, collars and cuffs before activating the Simulation for better stability." It shows all internal lines and shapes. Click one to get a folding gizmo, then rotate the red or green axis along the blue circle. Symmetric patterns fold symmetrically (ver 11). It also works after draping. — [Fold Arrangement](https://support.marvelousdesigner.com/hc/en-us/articles/47358260153881-Fold-Arrangement). **[Local]** The binary also has "Sync Fold Arrangement Angle".
- **Superimpose (Over) / (Under) / (Side)** (3D toolbar ▶ Select/Move ▶ 3D pattern right-click) arranges "a newly sewn Pattern onto its corresponding Pattern ... helpful when arranging facings, linings, cuffs, collars". It applies "only to Patterns that are already being sewn together". — [Superimpose](https://support.marvelousdesigner.com/hc/en-us/articles/47358389619481-Superimpose). CLO staff: Superimpose "places a pattern temporarily in a specific order based on sewing connections (on top, under or on the side of the seamline)". Side is for when "you built/simulated the shell of the garment and you just want to add a rib, it will place it next to the sewing line". — [CLO community: Superimpose and Sublayer](https://support.clo3d.com/hc/en-us/community/posts/4409649041689-Superimpose-and-Sublayer-what-the-difference-Plus-question-about-Puckering)
- **Smart Arrangement** (3D right-click): "Arrange a new Pattern onto an existing Pattern while maintaining 3D draping state". Sew the new pattern to a draped one, then Smart Arrangement places it "to where it is sewn as draped" (ver 3.0.0). — [Smart Arrangement](https://support.marvelousdesigner.com/hc/en-us/articles/47358423599257-Smart-Arrangement)
- **Reverse-Arrange ▶ Horizontally / Vertically** flips a pattern "while maintaining its curvature" (point-arranged patterns only). — [Reverse Arrangement](https://support.marvelousdesigner.com/hc/en-us/articles/47358425472921-Reverse-Arrangement-Horizontally-Vertically). **Flip Horizontally / Flip Vertically** rotates a pattern 180°. — [Flip Horizontally/Vertically](https://support.marvelousdesigner.com/hc/en-us/articles/47358424603161-Flip-Horizontally-Vertically)
- **Symmetric Arrangement** (2024.0; 3D right-click on a symmetrised pattern) mirrors that pattern's simulated state onto its symmetric partner. — [Symmetrical 3D State](https://support.marvelousdesigner.com/hc/en-us/articles/47358392697369-Symmetrical-3D-State-ver-2024-0)
- **Flatten** (Main Menu ▶ 3D Garment ▶ Flatten) turns closed shapes drawn on the avatar with 3D Pen (Avatar) into patterns. Enter = Flatten (Separate), Shift+Enter = Flatten (Merge). "Sewing lines are automatically established for adjacent Patterns." — [Flatten](https://support.marvelousdesigner.com/hc/en-us/articles/47358340247193-Flatten). **3D Pencil (Avatar)** (new in 2026.0) sketches on the avatar ▶ Convert to 3D Pen; "flattening both sides automatically sews the front and back together". — [3D Pencil (Avatar)](https://support.marvelousdesigner.com/hc/en-us/articles/55654873005081-3D-Pencil-Avatar)
- **Unfold** (Edit Pattern ▶ right-click a segment ▶ Unfold) mirrors a half pattern into a full one with no centre seam. — [Unfold](https://support.marvelousdesigner.com/hc/en-us/articles/47358434063001-Unfold). **[Local]** Binary messages include "Unfold could not be applied due to the selected segment properties. Tip: you can not unfold a curved line."

**Free placement**
- **Gizmo**: unified by default (3D toolbar ▶ Select/Move ▶ 3D pattern, *Simulation OFF*). The divided gizmo uses **Q** (select), **W** (move), **E** (rotate), set under Main Menu ▶ User Setting ▶ 3D ▶ Gizmo ▶ Divided Gizmo. Green arrow is Y, red is X, blue is Z, and the yellow square drifts freely. — [Move/Rotate Pattern with Gizmo](https://support.marvelousdesigner.com/hc/en-us/articles/47358192192665-Move-Rotate-Pattern-with-Gizmo)

- **Direct Positioning** (Select/Move ▶ click a pattern ▶ Direct Positioning icon): "The selected Pattern ... moves along with the mouse cursor" over garment or avatar, and a click places it. Shift restricts rotation. — [Direct Positioning](https://support.marvelousdesigner.com/hc/en-us/articles/47358256542361-Direct-Positioning)
- **Select/Move (3D)**: dragging with Simulate on pulls the cloth. With Simulate off, it switches to "pattern arrangement mode" and moves patterns rigidly. — [Select/Move (3D)](https://support.marvelousdesigner.com/hc/en-us/articles/47358168697497-Select-Move-3D)
- **Re-drape 3D Arrangement** (renamed from "Re-target Draping" in 2025.0; Main Menu ▶ 3D Garment) re-simulates a garment onto a custom avatar at its original size. - **Auto 3D Arrangement** (CLO 7.1; Main Menu ▶ 3D Garment) arranges patterns round the avatar from their shape using learned data. Applying symmetry and sewing first is recommended. Proceed, Back and Next step through the result. — [CLO Auto 3D Arrangement](https://support.clo3d.com/hc/en-us/articles/13200837772185-Auto-3D-Arrangement-ver-7-1). **[Local]** The MD 2026.0.315 binary contains the dialog (`DialogAutoArrangement`, "Auto 3D Arrangement", "3D patterns will be arranged in order according to their accuracy.", `Auto_Arrangement_Model_2_1_0`, `Adult_Auto_Arrangement_Point.arr`). No MD help article was found, so it may be CLO-only in the menus.
- Community workaround for avatars without usable points: place flat patterns so they do not start intersecting the body, and pin during the first run. One poster suggests zero gravity plus pins. — search-result summary of [polycount thread 168213](https://polycount.com/discussion/168213/how-to-use-marvelous-designer-for-cloth-simulation-in-custom-characters-no-arrangement-points) (page blocked to fetch, so not verified)

### Inferences
- The cape session's body points were up to 1 m off because Nardo's torso BVs were sized round the whole mesh, tail included. **MD's intended fix is in the avatar, not in the garment.** In Avatar Editor ▶ Arrangement, reduce the torso BVs' Radius X/Y (or set the back point's Offset), or add a dedicated BV between spine joints with new `Body_Back_*` points. Then save `.pan`, `.arr` and `.avt` so every later garment benefits. This is inferred from the editor fields; how BVs were auto-sized for Nardo is not documented.
- The GUI's mental model: points are a coarse first placement. Fine placement is Property Editor ▶ Arrangement (Position X/Y, Offset, Orientation) or the gizmo with simulation off. Secondary pieces (collar, lining, facing) are placed relative to sewn neighbours with Superimpose or Smart Arrangement, never from points. A model can follow the same order: shell by points, everything else by Superimpose.
- The serialised `ArrangementOffsetX/Y/Z` keys plausibly back the GUI's Position X, Position Y and Offset fields. That is inferred from naming only and not verified.
- Reset 2D Arrangement makes the 2D board layout the initial 3D layout. That is one reason pattern makers lay the board out deliberately (see section 6).

### Gaps
- No documentation gives the units or range of the Arrangement **Offset** field, or how auto-generated BVs pick their radii. Not found.
- Whether **Auto 3D Arrangement** is reachable from MD 2026.0's menus. The code is in the binary but no MD help page exists.
- No source covers tails specifically: whether to delete or ignore BVs wrapped round a tail, or add a "Tail" BV. Searches found nothing tail-specific.

## 2. Draping aids and how professionals sequence them

### Takeaway
MD gives a ladder of temporary aids:
- **pins**, which can be attached to the avatar
- **Tack** and **Tack on Avatar**
- **Freeze**, which makes a piece rigid but still collidable
- **Deactivate**, which removes a piece from the simulation altogether
- **Hide 3D Pattern** and **Archive**, which are display only
- **Strengthen** and **Solidify**
- **Shrinkage**, the **Layer** value, and particle distance or simulation presets

The documented professional sequence is to drape inner layers first, freeze them, drape the outer layer (with a raised Layer value or shrinkage if needed), then unfreeze, reset Layer to 0, restore shrinkage to 100%, and simulate again at finer particle distance. Every aid is meant to be **removed** afterwards.

### Cited Findings
- **Pins**: Main Menu ▶ 3D Garment ▶ Pin (Box) / Pin (Lasso), or **W + click** with Select/Move. Double-click an outline to pin a segment, or a pattern to pin the whole pattern. Pins work on internal lines too (ver 4.0.0). Drag pins or use the gizmo. In 2D, Shift+Ctrl-drag adds pins and Ctrl-drag removes them. The stated use is to "Affix specific portions of the Garment and utilize Pin similar to the Freeze function. It is also convenient when turning/flipping over collars, lapels, or cuffs." — [Create Pin](https://support.marvelousdesigner.com/hc/en-us/articles/47358422800537-Create-Pin)
- Deleting pins: pin right-click ▶ Delete Selected Pin / Delete All Pins; Edit ▶ … ▶ Delete All Pins on Selected Patterns; or W-click a pin. **Duplicate to Symmetric Pattern** arrived in 2024.2. **Attach Pin to Avatar / Attach All Pins to Avatar** sticks the pin to the nearest part of the avatar and is "commonly used ... for avoiding the Garment sliding off from the Avatar". Attached pins cannot be selected or moved; use Detach to release them. — [Pins](https://support.marvelousdesigner.com/hc/en-us/articles/47358146159769-Pins)
- **Tack** (Main Menu ▶ Sewing ▶ Tack ▶ Tack, or 3D toolbar): click two points on a draped garment and simulate, and the two points stay fixed to each other. The same tack appears in 2D, where it can be edited (ver 3.1.0). — [Tack](https://support.marvelousdesigner.com/hc/en-us/articles/47358185301017-Tack)
- **Tack on Avatar** (Main Menu ▶ Sewing ▶ Tack ▶ Tack on Avatar): click a garment point, then an avatar point. It "Temporarily fix[es] a point of a Garment to an Avatar". — [Tack on Avatar](https://support.marvelousdesigner.com/hc/en-us/articles/47358249329305-Tack-on-Avatar)
- **Line Tack** and **Line Tack on Avatar** (MD7) tack lines or shapes to each other or to the avatar. Edit Line Tack exposes a **Thread Length** property. **Edit Tack** drags endpoints, and Delete removes a tack. — [Line Tack on Garment](https://support.marvelousdesigner.com/hc/en-us/articles/47358252467993-Line-Tack-on-Garment); [Line Tack on Avatar](https://support.marvelousdesigner.com/hc/en-us/articles/47358294114969-Line-Tack-on-Avatar); [Edit Line Tack](https://support.marvelousdesigner.com/hc/en-us/articles/47358255439129-Edit-Line-Tack); [Edit/Delete Tack](https://support.marvelousdesigner.com/hc/en-us/articles/47358242158105-Edit-Delete-Tack)
- Community: use the Tack (garment) tool "from the left to right top button position and then adjust the thread length" to pull a collar closed while "the thread remain[s] invisible". — [MD community: How can I help collars fold correctly?](https://support.marvelousdesigner.com/hc/en-us/community/posts/48273576223129-How-can-I-help-collars-fold-correctly)
- **Freeze/Unfreeze** (right-click in 2D or 3D): "fasten Patterns like solid objects ... deactivated Patterns do not collide during Simulation; however, frozen Patterns do ... draping and freezing inner Garments first, then draping outerwear simultaneously, solves the occasional instabilities." — [Freeze/Unfreeze](https://support.marvelousdesigner.com/hc/en-us/articles/47358315135897-Freeze-Unfreeze)
- **Deactivate (Pattern & Sewing)** and **Deactivate (Pattern Only)**: "Deactivated Patterns are considered as nonexistence in the 3D window ... the rest of the Patterns simulate through". Used to stop pleats or slits collapsing, and it speeds up the simulation. — [Deactivate (Pattern & Sewing)](https://support.marvelousdesigner.com/hc/en-us/articles/47358273409945-Deactivate-Pattern-Sewing-Activate); [Deactivate (Pattern Only)](https://support.marvelousdesigner.com/hc/en-us/articles/47358262829849-Deactivate-Pattern-Only-Activate)
- **Deactivate Sewing (Selected)** (Edit Sewing ▶ right-click): use it "when Sewing Lines should be applied after the garment is draped, such as the back slits". Deactivated lines show white. — [Activate/Deactivate Sewing Lines](https://support.marvelousdesigner.com/hc/en-us/articles/47358440567833-Activate-Deactivate-Sewing-Lines)
- **Hide 3D Pattern / Hide All 3D Patterns** (3D right-click): "The hidden Pattern cannot be selected nor moved in the 3D window." This is the CLO doc — [CLO Hide 3D Pattern](https://support.clo3d.com/hc/en-us/articles/115012380548-Hide-3D-Pattern). **[Local]** "Hide 3D Pattern" is present in MD 2026.0.315's UI strings. MD 2026.0 adds **Archive/Unarchive** (2D/3D right-click), which hides unused patterns in 3D and shows them in 2D as a dotted outline — [Pattern Archive](https://support.marvelousdesigner.com/hc/en-us/articles/55690089563417-Pattern-Archive). It also adds **Isolate Selection (Shift+I)**, which is display only — [Isolate Selection](https://support.marvelousdesigner.com/hc/en-us/articles/55689610452889-Isolate-Selection)

### Inferences
- The cape session's freeze → pull → unfreeze → lengthen loop misused these aids. In the documented use, Freeze holds a **finished inner layer** while an outer one drapes over it. It is not a way to hold a deliberately short piece while it is regrown. Gravity 0 appears only as a special effect ("weightless"); the docs warn other values "will become unrealistic".
- A cape on a tailed avatar would use, in GUI terms:
  - **Attach Pin to Avatar** or **Tack on Avatar** at the neck and shoulder points to stop the cape sliding
  - **Deactivate (Pattern & Sewing)** to keep a slit or vent open while it settles
  - **Layer 1** on the shell while the lining settles beneath it
  - 20 mm particle distance while building, finer at the end, and all aids removed before the final simulation

### Gaps
- No official page states a single canonical "drape order" for a whole garment. The sequence above is assembled from CLO staff forum answers and MD's Freeze and Layer pages.
- No MD 2026.0 help page documents "Hide 3D Pattern" (only CLO's does). Its presence in MD comes from the binary's UI strings.

## 3. Layers and linings: Layer Clone, its automatic seams, and how a lining is really built

### Takeaway
**Layer Clone (Over/Under)** is documented for **padding, double-layer collars and cuffs**. It sews **every outline and every internal line** of the clone to the original, using **Turned** seams, and applies **linked editing**. That is exactly the 34 seams the cape session accepted. A lining built with it is only correct after the user **removes linked editing and deletes or re-sews the seams**, keeping only the rim or bagging edges. Alternatively the user builds the lining first or separately and layers it with Layer/Freeze/Deactivate, or sews it temporarily, Superimposes it Under, and replaces the temporary seams. MD 2026.0.315 has **no "Clone as Lining"** and **no Inside/Outside variant** of Layer Clone.

### Cited Findings
- MD **Layer Clone**: "Create an instance of the Pattern in its 3D state while sewing its Pattern outlines and Internal Lines to its instance's Pattern outlines and Internal Lines. Use the function to easily create padded jackets, collars, cuffs and other garments/details made with multiple layers". Location: Transform or Edit Pattern ▶ right-click ▶ **Layer Clone (Over)** (above the original) or **Layer Clone (Under)** (beneath it). — [Layer Clone](https://support.marvelousdesigner.com/hc/en-us/articles/47358338558745-Layer-Clone)
- CLO adds detail. "The cloned Pattern will follow along the mouse. Click on the 2D window to place the cloned Pattern." In 3D it is placed "directly over/under the original Pattern and its Pattern outlines and Internal Lines will be sewn to the original". "The cloned Patterns will be highlighted in light green in the 2D window and the linked editing will be applied." — [CLO Layer Clone (Over)](https://support.clo3d.com/hc/en-us/articles/115012378408-Layer-Clone-Over); [CLO Layer Clone (Under)](https://support.clo3d.com/hc/en-us/articles/115012378428-Layer-Clone-Under)

- The automatic seams are **Turned**. CLO staff: "When using Layer Clones, the created seamline is automatically set to Sewing Line Type: Turned ... ### Inferences
- What a lined cape needs, in GUI terms (lining shoulders sewn lining-to-lining, bagged at the hem and fronts, attached at the neck):
  - **Option A (identical pieces):** Layer Clone (Under) the shell pieces, then **Remove Linked Editing**. Delete every automatic seam except the outer bagging edges (fronts and hem) and the neckline. Sew lining shoulder to lining shoulder. Set the kept edge seams' Fold Strength to 0 or keep them Turned. Simulate with the shell frozen.
  - **Option B (pieces differ):** draft the lining as its own pieces and sew them to each other. Sew each temporarily to its shell, Superimpose (Under), then delete the temporary seams and sew the real edge seams. Settle with the shell on Layer 1, then return it to 0.
- The API cannot delete a seam (session report), so Option A is not reproducible over the bridge today. Option B, deliberate seams only, avoids the problem entirely. Either way, Layer Clone without the seam clean-up is **never** a finished lining in practitioners' eyes.

### Gaps
- No official MD or CLO help article walks through a bagged garment lining step by step. The workflows above come from CLO staff and community forum answers (2021–2023), and menu names may have shifted since.
- No source says whether Layer Clone's automatic seams can be skipped, for example with a "clone without sewing" option. None was found in the docs or the binary strings. Plain Copy/Paste (Ctrl+C/V in 2D or 3D) duplicates a pattern without seams but does not keep its 3D drape state the way Layer Clone does (inference from [Copy/Paste Patterns (3D)](https://support.marvelousdesigner.com/hc/en-us/articles/47358196143513-Copy-Paste-Patterns-3D)).

## 4. Collars and facings: keeping them upright, folded and stiff

### Takeaway
Collars and facings are built from:
- **internal lines with a Fold Angle and Fold Strength**, folded before simulation with **Fold Arrangement**
- **Bond** (interlining/fusible presets) for stiffness
- **Strengthen** for crisp folds while settling
- **Layer Clone** for a two-ply collar, with **Turned** seams
- **Superimpose (Side/Under)** to seat the collar or facing against what it is sewn to
- pins or tacks only to coax a fold, then removed

A fold line defaults to **180° (flat)**, so it does nothing until its angle is changed.

### Cited Findings
- **Fold Angle on internal lines** (Pattern Property Editor ▶ Fold ▶ Fold Angle): range 0–360°, "180˚ represents a flat state. The internal line is folded towards the front of the pattern as the fold angle is closer to 0˚, and is folded into the back of the pattern as the angle is closer to 360˚." **Fold Strength** runs 0–20. **Fold Rendering** gives soft or sharp edges and applies "only if Fold Arrangement is used on an Internal line". — [Fold Pattern](https://support.marvelousdesigner.com/hc/en-us/articles/47358354961049-Fold-Pattern)
- **Variable Fold Angle** (Uniform or Variable, tapering to 180° at one end) is **new in 2026.1**, so it is not in 2026.0.315. — [Internal Line Variable Fold Angle](https://support.marvelousdesigner.com/hc/en-us/articles/59783425428121-Internal-Line-Variable-Fold-Angle)
- Collars that "all stand up": "Default is 180, which means the cloth at the line will lie flat. You have to change it to nearly 0 to have it fold at all". Also: "move the red line to coincide with where the self-fold occurs, and extend the pattern outer edges such that downward portion (the 'fall') of the collar is the size you want." — [MD community: Collars](https://support.marvelousdesigner.com/hc/en-us/community/posts/48277232788249-Collars)
- Collars that "pop back up": check there is no pressure on one side; set "the collision offset distance is 1.5mm at human scale"; check "the fabric is not a stiff preset ... solidify is off"; and "Ensure the internal line for the bend fold angle has a strength setting that keeps the fold down." — [MD community: How can I help collars fold correctly?](https://support.marvelousdesigner.com/hc/en-us/community/posts/48273576223129-How-can-I-help-collars-fold-correctly)
- A more natural shirt collar: toggle Fold ▶ Fold rendering, "play with the solidify option and delete the internal line entirely". — [MD community: About adjust collar silhouette](https://support.marvelousdesigner.com/hc/en-us/community/posts/48276748288153-About-adjust-collar-silhouette)
- **Fold Arrangement** pre-folds "Seam Allowances, collars and cuffs before activating the Simulation for better stability". — [Fold Arrangement](https://support.marvelousdesigner.com/hc/en-us/articles/47358260153881-Fold-Arrangement)
- **Strengthen** gives "clean folds where fold angles are applied" (temporary; Ctrl+H). — [Strengthen / Unstrengthen](https://support.marvelousdesigner.com/hc/en-us/articles/47358253657497-Strengthen-Unstrengthen)
- **Bond (interlining)**: Property Editor (Pattern or Internal Shape) ▶ Bond/Skive ▶ Bond. The area shows semi-transparent orange and drapes "stiffer as if an interlining has been fused". Pick a preset, or edit Detail. — [Bond](https://support.marvelousdesigner.com/hc/en-us/articles/47358358998809-Bond). CLO's preset list: Fusible (Common) tricot 47 gsm; Fusible (Lapel) wefted 30 gsm; Fusible (Nonwoven) 40 gsm; Fusible (Nonwoven_Small Parts) 32 gsm; Reinforcement (Pocket Bone) 38–42 gsm; **Reinforcement (Undercollar) hair cloth 180 gsm**. — [CLO Bond: How to Add Interlining / Fusible / Reinforcement](https://support.clo3d.com/hc/en-us/articles/115000574207-Bond-How-to-Add-Interlining-Fusible-Reinforcement)
- **[Local]** MD 2026.0.315's app-data cache (`%LOCALAPPDATA%\CLO Virtual Fashion\Marvelous Designer Enterprise Offline Annual\<pid>\100x\`) holds the bond presets "Fusible (Body).fab", "Fusible (Lapel).fab", "Fusible_NoneWoven (Reinforcement).fab", "Fusible_NoneWoven (Small Parts).fab", "Fusible (Pocket Bone).fab" and **"Fusible (Under Collar).fab"**. So MD's preset names differ slightly from CLO's list.
- **Layer Clone** is the documented route to double-layer "collars, cuffs". — [Layer Clone](https://support.marvelousdesigner.com/hc/en-us/articles/47358338558745-Layer-Clone). **Sewing Line Type ▶ Turned** sews "Double layered Patterns ... together crisp and flat" — [Sewing Line Type](https://support.marvelousdesigner.com/hc/en-us/articles/47358411103001-Sewing-Line-Type). With Turned, Fold Strength and Angle are locked (ver 4.0.0) — [Fold Seam Line](https://support.marvelousdesigner.com/hc/en-us/articles/47358411649305-Fold-Seam-Line). **Weld Turned Seamlines** is new in 2026.0 — [2026.0 feature list](https://support.marvelousdesigner.com/hc/en-us/articles/55837641308313-Marvelous-Designer-2026-0-New-Feature-List); **[Local]** strings "Weld Turned Sewing Lines" and "Apply/Unapply Turned Sewing Line Type".
- **Superimpose** is for "facings, linings, cuffs, collars", and **Side** places a piece "next to the sewing line" (rib on a built shell). — [Superimpose](https://support.marvelousdesigner.com/hc/en-us/articles/47358389619481-Superimpose); [CLO community](https://support.clo3d.com/hc/en-us/community/posts/4409649041689-Superimpose-and-Sublayer-what-the-difference-Plus-question-about-Puckering)
- **Lapel facing recipe** (experienced CLO community member, 2019):
  1. Fold the lapel and freeze it.
  2. Mirror the facing.
  3. Use **Clone as Internal Shape** on the facing and align it on the front.
  4. Sew the facing to that internal shape with **Turned** seams.
  5. Reduce Add'l Thickness-Collision.
  6. **Superimpose Under** the facing.
  7. **Bond** the facing for stiffness.

  A second member clones the lapel Under, puts the jacket on Layer 1, sets collision 1 mm and render thickness 1 mm, and **Strengthens** the lapel. A third advises a single layer with Add'l Thickness rendering and "Curved Side Geometry > Double Sided". — [CLO community: Sewing/Arranging facing for lapel](https://support.clo3d.com/hc/en-us/community/posts/360033634853-Sewing-Arranging-facing-for-lapel)
- Pins are "convenient when turning/flipping over collars, lapels, or cuffs". — [Create Pin](https://support.marvelousdesigner.com/hc/en-us/articles/47358422800537-Create-Pin)
- Collar drafting in Epic's MD sweater tutorial: measure the neckline by selecting the front and back neckline segments, then draw a rectangle of that length with the Rectangle tool. — search-result summary of [Epic: Making a sweater with Marvelous Designer (UEFN)](https://dev.epicgames.com/documentation/en-us/uefn/making-a-sweater-with-marvelous-designer-in-unreal-editor-for-fortnite) (not fetched)

### Inferences
- A **stand collar**, such as the cape's pointed "vampire" collar, would be built as:
  1. A collar piece (or two plies via Layer Clone Over/Under with Turned edge seams) sewn to the neckline.
  2. **Superimpose (Side)** to stand it on the seam.
  3. **Bond** with the "Fusible (Under Collar)" preset, or a stiffer fabric, to keep it up.
  4. Optionally a roll line at a Fold Angle of a little under 180° on the inside, **Strengthen** while settling, then Unstrengthen.

  The cape session's collar caught on the jaw. In the GUI that is fixed with Fold Arrangement, pins or Superimpose before simulating, not by shrinking and regrowing the piece.
- A fold line at 180° is a no-op. A model that adds fold lines must also set their angle and strength.

### Gaps
- No official MD page for a *stand* collar specifically (most guidance is about shirt collars and lapels). There are no measured defaults for Fold Strength on new internal lines.
- MD's help pages do not document how the bond presets map to stiffness numbers. The `.fab` decode in roadmap P4 would answer that.

## 5. Seams in MD: tools, direction, editing, deleting and auditing

### Takeaway
MD's seam vocabulary:
- **Segment Sewing** (whole segment to whole segment)
- **Free Sewing** (any interval, with a typed length)
- **M:N** and **1:N** variants (several segments to several, N divided in proportion)
- all of the above also in 3D

Direction is shown by **directional notches**, and crossed notches give a twisted seam. Seams are inspected and edited with **Edit Sewing (B)**. Clicking one shows its pair as a dotted line, and it is deleted with **Delete Sewing** or the Delete key. Audits use **Check Sewing Length** (flags differences over 5 mm), the live length-difference readout (red over 1 inch), **Show Threads**, **Select All Sewn (Ctrl+Alt+A)** and the Statistics HUD's **Sewings** count.

## 6. The 2D board: how professionals lay pieces out

### Takeaway
The 2D window is the pattern maker's primary view, and its layout seeds the first 3D layout (**Reset 2D Arrangement** mirrors it). Its tools:
- grainline set per piece with **Edit Texture** (Rotate Grainline, Align Grain Parallel to Selected) or Property Editor ▶ Grain Direction
- symmetric halves made with **Clone Pattern with Linked Editing ▶ Symmetric Pattern (With Sewing)** or **Unfold Symmetric Editing (with Sewing)**
- lengths changed numerically with **Transform Pattern** (typed distances), **Offset Pattern Outline** or the 2026.0 "Preserve 3D Garment Shape on 2D Scaling", never by repeated point nudges
- display aids: Show Pattern Names, Show Grainline, Show Pattern Layer and Lock

### Cited Findings
- **Reset 2D Arrangement** sets the 3D layout "identical to 2D window state". — [Reset 2D Arrangement](https://support.marvelousdesigner.com/hc/en-us/articles/47358384849177-Reset-2D-Arrangement)
- **Transform Pattern (A)**:
  - Marquee-select; Ctrl-drag selects whatever the box touches (2024.0).
  - Shift or Ctrl while moving constrains the direction.
  - "right click or hit F1 key ... while moving the Pattern to type in distance moved."
  - Drag box handles to scale; the rotation handle rotates.
  - Double-click the pivot to transform about it.
  - [Select/Move/Transform Pattern](https://support.marvelousdesigner.com/hc/en-us/articles/47358185711257-Select-Move-Transform-Pattern)
- **Offset Pattern Outline** (right-click on a selected outline or segment): **Extend** or **Retract** (MD10) by a **Distance** times a Number of Offsets. It can **Create Internal Line** at the old outline, and offers side-segment and corner options. — [Offset Pattern Outline](https://support.marvelousdesigner.com/hc/en-us/articles/47358359572121-Offset-Pattern-Outline). **Offset as Internal Line** makes parallel lines at typed distances (for example hem or facing lines). — [Offset as Internal Line](https://support.marvelousdesigner.com/hc/en-us/articles/47358442871705-Offset-as-Internal-Line)
- MD 2026.0 key feature: "Preserve 3D Garment Shape on 2D Scaling". It is listed with no help article. — [MD 2026.0 New Feature List](https://support.marvelousdesigner.com/hc/en-us/articles/55837641308313-Marvelous-Designer-2026-0-New-Feature-List)
- **Grainline**: Edit Texture tool (Main Menu ▶ Materials ▶ Texture ▶ Edit Texture) ▶ Rotate Grainline, or **Align Grain Parallel to Selected** (right-click, then click a segment), or Property Editor ▶ Fabric ▶ Grain Direction. "Simulate once it is adjusted." — [Edit Texture](https://support.marvelousdesigner.com/hc/en-us/articles/47358423478169-Edit-Texture). CLO 2024.2 adds Grain Direction, Grain Orientation (one, two or four way) and **Grainline Lock**. — [CLO Grainline](https://support.clo3d.com/hc/en-us/articles/37494551581593-Grainline)
- **Symmetric pieces**:
  - Right-click ▶ **Clone Pattern with Linked Editing ▶ Symmetric Pattern (With Sewing) / Symmetric Pattern / Instance Pattern**. Symmetric outlines show light blue.
  - **Apply Linked Editing** or **Remove Linked Editing** on existing pairs.
  - [Linked Editing](https://support.marvelousdesigner.com/hc/en-us/articles/47358366174233-Linked-Editing)
  - **Mirror Paste (Ctrl+R)** — [Mirror Paste](https://support.marvelousdesigner.com/hc/en-us/articles/47358296814745-Mirror-Paste)
  - **Unfold Symmetric Editing (with Sewing)** (Edit Pattern ▶ right-click a line, ver 5.1.0) edits one piece symmetrically about its centre line. — [Unfold Symmetric Editing](https://support.marvelousdesigner.com/hc/en-us/articles/47358430239513-Unfold-Symmetric-Editing-with-Sewing-ver5-1-0)
  - **Merge** symmetric patterns into one — [Merge Symmetric Patterns](https://support.marvelousdesigner.com/hc/en-us/articles/47358369267481-Merge-Symmetric-Patterns)
  - **Unfold** a half pattern — [Unfold](https://support.marvelousdesigner.com/hc/en-us/articles/47358434063001-Unfold)
- **2D display** (2D window icons):
  - **Show Pattern Names**, **Show Pattern Layer** (2024.1), **Show Line Length / Angle**, **Show Grainline**, **Show Symmetric/Instance Lines**
  - Random Color Surface
  - **Lock All Pattern Outlines / Internal Lines / Guidelines / Remesh Patterns**
  - [2D Window Display Icons](https://support.marvelousdesigner.com/hc/en-us/articles/47358205499033-2D-Window-Display-Icons-Ver-5-1-4-and-above)
  - **Lock Pattern** (right-click) — [Lock](https://support.marvelousdesigner.com/hc/en-us/articles/47358357822489-Lock)

Click on the 2D window to place"). — [CLO Layer Clone (Over)](https://support.clo3d.com/hc/en-us/articles/115012378408-Layer-Clone-Over); [Clone as Pattern/Internal Shape](https://support.marvelousdesigner.com/hc/en-us/articles/47358332785689-Clone-as-Pattern-Internal-Shape)

### Inferences
- The 2D board is laid out like the garment: pieces separated, grainline up, symmetric partners side by side, and linings and trims in their own band. - No official guidance on 2D board organisation conventions (front/back sides, grouping) was found. It is likely taught in video tutorials (the "Quick Start" and "8. ## 8. Capes and cloaks in MD/CLO: construction and placement

### Takeaway
No official MD or CLO help article or tutorial covers capes, and the community material found is mostly commercial (Skillshare, Gumroad, Cubebrush, CGTrader). The consistent practical pattern from what was found:
- full-length pieces arranged on the body
- **anchored at the shoulders or neck to the avatar** with pins or tacks
- simulated with minimal pins
- inside-out folds fixed by re-simulating separated layers
- collars and linings built with the general collar and lining tools above

### Cited Findings
- The "Superhero cape" MD resource: "The pattern for this one is quite simple, but collecting and draping the fabric has been done for you. All you need to do is pin the two shoulder points onto your chosen avatar!" — search-result summary of [Cubebrush: Cape Superhero – MD resource](https://cubebrush.co/kieran_xp/products/mrujw/cape-superhero-marvelous-designer-resource) and [ArtStation listing](https://www.artstation.com/marketplace/p/1qb8/cape-superhero-marvelous-designer-resource) (not fetched)
- Skillshare "Cape & Cloak in Marvelous Designer": when a cape folds inside out, waiting for the simulation to finish sometimes fixes it, or separate the layers and simulate again. — search-result summary of [Skillshare class](https://www.skillshare.com/en/classes/Cape-Cloak-in-Marvelous-Designer/103489479) (fetch blocked, HTTP 403; unverified)
- A course covering "Capes Cloaks, Hoods and Hats" exists, but its lesson detail is not public. — search-result summary of [Camille Kleinman, ArtStation](https://camillekleinman.artstation.com/projects/ZndNw) (not fetched)
- Garments sliding off the shoulders (MD support thread): pull the top parts over the shoulders, use arrangement points, and "reset your patterns and arrange them and bring it higher in the 3D window before simulating". — search-result summary of [MD community post 48272833544601](https://support.marvelousdesigner.com/hc/en-us/community/posts/48272833544601) (not fetched)
- A medieval hooded-cloak asset on Fab was modelled in MD, cleaned in Blender and textured in Substance; it notes per-character weight-paint fixes round the shoulders. — search-result summary of [Fab listing](https://www.fab.com/listings/43c6e3ea-3991-4947-9811-dadfdb464251) (not fetched)

### Inferences
- A GUI-faithful build of the user's reference cape (long black cape, pointed stand collar, red lining throughout, arm slits, tail vent):
  1. Save a **3D State** in History as a checkpoint.
  2. Fix the avatar's back BV (Avatar Editor ▶ Arrangement) so `Body_Back_*` points sit on the back, or place the back with **Direct Positioning** or the gizmo with simulation off.
  3. Draft a full-length back and two fronts with grainline set. Use symmetric fronts via Clone Pattern with Linked Editing ▶ Symmetric Pattern (With Sewing). Draft arm slits and the tail vent as gaps in the side and centre-back seams (a CB vent is left unsewn, or sewn and **deactivated** while settling).
  4. Arrange the back on body-back points and the fronts on body-front points. Sew the shoulders with **Segment Sewing**, checking the notches.
  5. Anchor the neck or shoulders with **Tack on Avatar** or **Attach Pin to Avatar**, then simulate on Normal at 20 mm.
  6. Collar: sew it to the neckline, use **Superimpose (Side)**, **Bond** with Fusible (Under Collar), then Strengthen while settling.
  7. Lining, deliberate seams only:
     - Either draft separate pieces sewn lining-to-lining at the shoulders, or Layer Clone (Under) with Remove Linked Editing and every automatic seam deleted except the fronts, hem and neckline.
     - Seat the lining with Superimpose (Under) or the Layer-1 shell sequence.
     - Set Fold Strength to 0 on the bagged edges.
  8. Remove pins and tacks, set Layer back to 0, refine particle distance, and do the final simulation.

  This is a synthesis of the cited tools. No source describes this exact cape.

### Gaps
- No primary-source cape or cloak tutorial with step-level detail was retrievable. YouTube transcripts were not available to this research, and the paid courses are behind paywalls. The cape-specific claims above come only from search-result summaries. A companion note in this folder (`pattern_drafting_capes.md`) covers pattern shapes.
